# 🐾 Tiny Pet

Tiny Pet is a small virtual pet prototype built with plain HTML, CSS, and JavaScript.

Your pet now has three life stages (egg, child, adult), and these core stats:
- Hunger
- Happiness
- Energy
- Care/Neglect

These stats change over time... even while you’re away. Check in, care for your pet, and see how it reacts.

## Features
- Real-time stat decay (offline progress)
- Simple interactions: Feed, Play, Rest
- Mood system with expressive feedback
- Lightweight save system using localStorage
- Designed to be tiny, cozy, low-pressure fun
