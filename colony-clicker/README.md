# Colony Clicker v0.3

A minimal idle/clicker game prototype.

Features:
- Manual resource gathering
- Automated food production (fields)
- Population growth & housing limits
- Food consumption scaling with population
- Storage buildings (sheds)
- Colony status feedback

Built with plain HTML, CSS, and JavaScript.

## Future Plans
- Additional buildings
- Events (raids, migrants)
- Save/load

### Design Goals
- Simple, readable systems
- No frameworks
